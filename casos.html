Proyecto en Desarrollo / Fase Final

Modernización de Sistema de Gestión de Seguros & App Móvil

El Desafío Técnico

Migrar un sistema de escritorio integral de seguros a un entorno web accesible desde navegador y dispositivo móvil. El reto principal consistía en conservar las complejas reglas del negocio y permitir consultas veloces a una base de datos relacional de gran volumen sin interrumpir la operación.

La Solución Integrada

Diseño de una arquitectura limpia separando el backend mediante una API REST en Spring Boot y un frontend web ágil. Complementariamente, se desarrolló una aplicación móvil orientada a consultas inmediatas de datos de vehículos y coberturas en tiempo real.

Stack Utilizado

Spring Boot Java MySQL HTML5 / JavaScript React Native / Expo Linux VPS

Resultados Previstos

Acceso remoto seguro para operarios y clientes, eliminación de dependencias de red local/VPN, y tiempos de respuesta reducidos a milisegundos en búsquedas críticas de vehículos.

* Los datos mostrados en las capturas son ficticios y anonimizados por motivos de confidencialidad.
