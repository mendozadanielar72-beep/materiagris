Proyecto en Desarrollo / Fase Final

Modernización de Sistema de Gestión de Seguros & App Móvil

El Desafío Técnico

Migrar un sistema de escritorio a un entorno web y móvil optimizado, manteniendo reglas de negocio complejas sin interrumpir operaciones.

La Solución

Arquitectura desacoplada con API REST en Spring Boot, frontend web dinámico y app móvil en React Native para consultas de vehículos en tiempo real.

Stack Utilizado

Spring Boot Java MySQL JavaScript React Native
